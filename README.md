# ☀️ Summer Store

Summer Store is a modern and responsive summer-themed e-commerce web application built with **Next.js 15**, **Tailwind CSS**, and **HeroUI**.  
Users can browse summer products, view product details, and enjoy a clean shopping experience.

---

# 🚀 Features

- 🛍️ Product Listing Page
- 📄 Product Details Page
- ⚡ Dynamic Routing with Next.js App Router
- 🔍 Dynamic Metadata for SEO
- 📱 Fully Responsive Design
- 🎨 Modern UI with Tailwind CSS & HeroUI
- ⏳ Loading Skeletons
- 🔐 Authentication Integration (Better Auth)
- 🌐 Google Login Support
- 🚀 Vercel Deployment Ready
